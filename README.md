A full-featured, cross-platform node-based visual programming / dataflow editor component for Delphi (works on **Windows**, **Linux**, **Android** and **MacOS**).

Perfect for creating visual scripting tools, shader editors, game logic editors, automation tools, or any application that needs a node graph UI.

---

### ✨ Features

- **Modern node UI** with customizable header/body colors
- **Two pin types**: `Exec` (flow) and `Data` (values)
- **Rich inspector** — edit node properties, pins, values (float, int, string, boolean, bitmap, point, JSON)
- **Full undo/redo** system with command pattern
- **Save / Load** as JSON (compatible with custom nodes)
- **Snap to grid**, zoom, pan, frame all, fit to selection
- **Copy / Paste / Cut / Duplicate** nodes (with links)
- **Reroute nodes**, **Comment / Frame** nodes
- **Drag & drop** node creation from context menu or toolbar
- **Validation** system
- **Execute/Debug** system
- **Highly extensible** — easy to register your own node classes
- **Cross-platform** (Delphi, FMX)
- **Graphic nodes** (transforming, transition, distortion, composite)
- **Math nodes** (base, geometry)
- **Logic nodes** (comparers, logic math)
- **Flow nodes** (loops, sequences, switch)
